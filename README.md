# Inventario de Dispositivos de Red

**Proyecto de Programación de Redes · E-PRDS-2**

## 1. Descripción del proyecto

Desarrollo de una API utilizando Python y FastAPI para administrar un inventario de dispositivos de red. El sistema permitirá registrar, consultar, actualizar y eliminar dispositivos mediante solicitudes HTTP.

## 2. Hipótesis

Si se desarrolla una API para gestionar el inventario de dispositivos de red, entonces se podrá centralizar y agilizar el registro, consulta y actualización de los equipos, reduciendo errores de administración y facilitando el control de la infraestructura de red.

## 3. Objetivo general

Implementar un sistema de gestión de dispositivos de red que permita mantener organizada y actualizada la información de los equipos.

## 4. Tecnologías utilizadas

- Python
- FastAPI
- Pydantic
- Git
- GitHub

## 5. Funcionalidades

- Registro de dispositivos.
- Consulta de dispositivos.
- Actualización de información.
- Eliminación de dispositivos.
- Administración de nombre, tipo, dirección IP y estado de actividad.

## 6. Equipo de desarrollo

Proyecto colaborativo de tres integrantes.

- API y datos.
- Integración.
- Calidad y seguridad.

## 7. Estado del proyecto

En desarrollo.
